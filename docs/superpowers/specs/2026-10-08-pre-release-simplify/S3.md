## S3-2: Collapse six redundant conditions and duplicates in new Drive and account code

Each item stands alone and is behaviour-identical.

**(a) Redundant `flag` guard.** `src/features/googleDrive/config.ts:65`:
```diff
-  const hostAllowed = flag !== 'false' && (flag === undefined || flag === 'true')
+  const hostAllowed = (flag === undefined || flag === 'true')
```
`(flag === undefined || flag === 'true')` already implies `flag !== 'false'`.

**(b) Nested size check.** `src/features/googleDrive/prepareArchive.ts:49-52`:
```diff
-      if ((asset.size !== null && asset.size !== blob.size) || blob.size + total > sizeLimit) {
```

`if (A || B) { if (B) throw X; throw Y }` is the same as `if (B) throw X; if (A) throw Y`. The limit still wins. Both conditions are pure.

**(c) Comparisons written twice.** `src/features/googleDrive/publishDataset.ts:65-71`, inside `complete()`:
```diff
-      if (Number(file.size) > 0 && (file.size !== String(current.archive!.blob.size) || file.md5Checksum !== current.archive!.md5)) {
```

**(d) Duplicate error literal.** `src/features/googleDrive/publishDataset.ts:54` builds `new GoogleDrivePublishError('The dataset changed. Start a new Drive publication.')` inline. **Where:** `src/features/datasetPublishing/preparePublication.ts:95-101` and `src/features/googleDrive/prepareArchive.ts:106-110`.

```diff
+export async function pinHfAssetUrl(value: string, resolveRevision: (repoId: string, revision: string) => Promise<string>): Promise<string> {
```

## Noticed: behaviour, not a simplification (for code review)

Drive expires whichever session is current when an answer is 401 or insufficient-scope (`googleDrive/api.ts:142-147`, `upload.ts:103`). HF expires only the session that made the request (`datasetAccess.ts:49`). If the user signs in again while a Drive request is in flight, that request's 401 can sign them out.
