Open source · In your browser

Explore your 3D reconstructions.

ColmapView displays COLMAP cameras, images, point clouds, and Gaussian splats in an interactive web viewer. Inspect a dataset, adjust the view, and share the results.

Local files

View without an account

Drop supported files, folders, or archives into the viewer. Reconstruction processing and rendering run in your browser. Selecting local files does not upload them to a ColmapView server.

Remote datasets

Open a dataset URL

Load supported public archives, Hugging Face datasets, and manifests. Your browser retrieves files from the source you choose; the source controls access and availability.

Optional account access

Read private datasets

Where sign-in is enabled, connect Google Drive and select a private ZIP or TAR archive through Google's file picker, or connect Hugging Face to open a private dataset, folder, manifest, or archive. Your provider asks you to approve access.

Explicit publication

Publish the current dataset

Where publishing is enabled, create a new public Hugging Face dataset or upload a private ZIP to Google Drive. Drive link sharing is optional. Publication can include original images, masks, splats, viewer settings, and a preview.

Why account permissions are requested

Google Drive uses per-file access for archives you select through Google's file picker and dataset ZIPs created by the app. Pasting a private link alone does not grant access. Hugging Face read access lets the viewer download private repository files; publishing requests permission to create and write a new dataset repository.

Connecting an account does not start a publication. Tokens stay in the current tab's memory. Disconnecting ends future authenticated requests but does not erase files already loaded in the browser or uploaded to a provider. See the privacy policy for data handling and removal options.

Availability

ColmapView is under active development. Account features depend on the configuration of the viewer you open and on provider approval and account permissions. Development previews may use providers' testing mode.

Google Drive loading and publishing are available only on the hosted viewer at colmapview.opsiclear.com. Drive loading supports public ZIP and TAR links, including compressed TAR, and private archive selection through Google's file picker. Drive folder loading is not available; the Drive publisher creates ZIP files. Other local and remote sources retain their supported archive formats. The current Hugging Face publisher creates public dataset repositories. The viewer shows which account and publishing features are available in the version you open.
